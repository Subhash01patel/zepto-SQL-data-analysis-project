# zepto-SQL-data-analysis-project


A real-world SQL analytics project built using Zepto product and inventory data to perform business analysis, inventory tracking, pricing analysis, and sales insights generation.

This project demonstrates how SQL can be used to clean raw business data, perform exploratory analysis, and generate actionable insights for a quick-commerce platform like Zepto.

---

# 📌 Project Overview

The project focuses on analyzing Zepto’s product inventory dataset using SQL to solve real business problems related to:

- Inventory Management
- Product Pricing Analysis
- Discount Analysis
- Revenue Estimation
- Product Categorization
- Stock Availability Tracking

The project simulates how data analysts use SQL in e-commerce and quick-commerce companies to generate business insights from raw operational data.

---

# 🔥 Key Business Problems Solved

- Identified products with highest discounts
- Detected high-value products that are out of stock
- Estimated category-wise revenue
- Analyzed average discount across categories
- Calculated product price per gram for value comparison
- Categorized products based on weight
- Measured inventory weight across categories
- Performed stock availability analysis
